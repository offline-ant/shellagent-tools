> **Archived.** No longer maintained. Current Pi tooling lives in [Phimacs](https://github.com/offline-ant/phimacs).

Useful CLI tools for LLMs. 

- code-scan : Search a folder for functions / structs / enums in (Js, python, rust). Print line number, comments, and function signature.
- background : Start, stop, read stdout, write stdin for a long running process.
